Command palette script for Wikimedia projects, still a work in progress

Load with

```js
mw.loader.load( 'https://en.wikipedia.org/w/index.php?title=User:The_wub/commandPalette.js&action=raw&ctype=text/javascript' );
```

Then hit `Cmd+Shift+P`

# Features

- automatically includes all commands in tabs and standard menus
- press `@` to see other language versions of page
- press `#` to see sections of page
    - includes DiscussionTools metadata on enabled pages
